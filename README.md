# 🐍 CURSO PYTHON — MUNDO 1

### Meus primeiros passos no mundo da programação com Python!

Este repositório reúne meus estudos, exercícios e práticas desenvolvidos durante o **Curso de Python 3 — Mundo 1**, ministrado pelo professor **Gustavo Guanabara**, do canal [Curso em Vídeo](https://www.youtube.com/@cursoemvideo).

O objetivo é registrar minha evolução no aprendizado da linguagem Python, colocando em prática os conceitos apresentados durante as aulas e desenvolvendo meu raciocínio lógico e minha capacidade de resolver problemas através da programação.

---

## 🎯 Objetivo do Repositório

Organizar e documentar os exercícios realizados durante o curso, demonstrando na prática os conhecimentos adquiridos ao longo da jornada de aprendizado.

## 📚 Conteúdos e Exercícios

Os exercícios disponíveis neste repositório trabalham conceitos fundamentais de Python, como:

- Variáveis e tipos de dados.
- Entrada e saída de dados.
- Operadores matemáticos.
- Operações e expressões aritméticas.
- Manipulação de números.
- Conversão de unidades.
- Cálculos matemáticos.
- Estruturas básicas de programação.
- Formatação e apresentação de resultados.

## 🚀 Como executar os exercícios

Para executar os programas, você precisa ter o Python instalado em seu computador.

**1. Clone o repositório:**

```bash
git clone https://github.com/Uelisson-Barreto-Dev/CURSO-PYTHON-MUNDO-1.git
```

**2. Entre na pasta do projeto:**

```bash
cd CURSO-PYTHON-MUNDO-1
```

**3. Escolha o exercício desejado e execute:**

```bash
python nome_do_arquivo.py
```

No Windows, também é possível utilizar:

```bash
py nome_do_arquivo.py
```
